# Linear Search - Java

A simple Java program to search for an element using the Linear Search algorithm.

## Features
- Takes elements from the user
- Searches for a given element
- Displays the position of the element

## Technology Used
Java

## DSA Topic
Searching - Linear Search

## Output

Enter number of elements: 5
Enter elements:
10 25 30 45 50

Enter element to search: 30
Element found at position 3
